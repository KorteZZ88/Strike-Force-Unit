# env_rope

Энтити, представляющая верёвку.

## Настройки

- **`Name`** - Имя энтити
- **`Segments`** - Количество сегментов верёвки
- **`Disable Use`** - Устанавливает, можно ли игрокам взаимодействовать с верёвкой
- **`Ending Model`** - Модель последнего сегмента
- **`Body Model`** - Модель остальных сегментов
- **`End Target`** - Имя энтити, которая перемещается к свободному концу верёвки. Её дочерние энтити следуют за ней через обычную систему parent
- **`End Target Angles`** - Режим ориентации: сохранить исходные углы, раскачивать с сохранением исходного yaw или повторять углы последнего сегмента
